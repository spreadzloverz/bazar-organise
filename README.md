## Structure
```
index.html              → Page principale (grille 13 projets)
about.html              → À propos + contact
projets/[slug].html     → 13 pages projets individuelles
assets/images/[slug]/   → Dossiers images par projet (à remplir)
CNAME                   → bazarorganise.fr
projects.json           → Données structurées
```

## Ajouter les images
Glisser les images dans le dossier de chaque projet :
```
assets/images/[slug]/01.jpg
assets/images/[slug]/02.jpg
...
```
